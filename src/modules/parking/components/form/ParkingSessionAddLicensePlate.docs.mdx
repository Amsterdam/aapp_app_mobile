## When to use

Use this section inside the parking session flow when someone is choosing a vehicle for the current visit and may want to save that vehicle for later sessions.

## Key states to review

- default entry state before the save option is enabled
- loading feedback while saved license plates are being fetched
- the follow-up naming states covered by the dedicated name-field story

## Do's and don'ts

### Do's

- Keep the license plate entry focused on the current parking action
- Review the save toggle together with the revealed naming step
- Check that loading feedback appears before the rest of the form

### Don'ts

- Assume the save option is always relevant for one-off visits
- Hide loading states that interrupt the form before saved plates are known
- Treat the optional save flow as required for starting a session
