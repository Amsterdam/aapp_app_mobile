Use this bottom-sheet step when someone needs to choose a vehicle for the current parking session, either from saved plates or by entering a new one.

<Primary />

## When to use

Use this bottom sheet in the parking session flow whenever vehicle selection needs focused attention without leaving the current form.

## Key states to review

- the standard combined state with both add and saved-plate sections
- loading feedback while saved vehicles are still being prepared
- the empty saved-plates state for first-time use
- the forced saved-list state where new entry is not available
- fuller saved-plate lists that increase the amount of content in the sheet

## Do's and don'ts

### Do's

- Review how the add flow and saved-list flow compete for attention in one sheet
- Check the empty and forced-list variants because they change the available choices
- Verify that longer saved lists still feel easy to scan and tap

### Don'ts

- Assume everyone can always add a fresh license plate in this step
- Let loading feedback obscure whether the sheet is still usable
- Treat first-time and repeat-use scenarios as the same experience
