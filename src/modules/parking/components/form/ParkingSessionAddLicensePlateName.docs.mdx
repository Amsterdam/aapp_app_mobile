## When to use

Use this field only after someone has chosen to save the current license plate for later reuse.

## Key states to review

- a blank name field for a new vehicle
- an existing saved vehicle where the current name can be adjusted
- the maximum-saved warning that blocks additional entries

## Do's and don'ts

### Do's

- Encourage names that help someone recognize the vehicle later
- Check that duplicate saved vehicles explain that the name can still change
- Review the storage limit warning in the same flow as the save toggle

### Don'ts

- Ask for a name before someone has chosen to save the vehicle
- Suggest that a duplicate vehicle creates a second saved entry
- Hide the storage limit until after someone finishes the form
